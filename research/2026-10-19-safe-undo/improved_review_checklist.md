Date: October 19, 2026. The NeurIPS Paper Checklist is used only as a review aid: https://neurips.cc/public/guides/PaperChecklist . No conference approval or submission compliance is claimed.

| Check | Required evidence and scope |
| --- | --- |
| Claims | Compare observed saved states and actual controller status. Keep the baseline's formal decision claim separate from autonomous model behavior. |
| Contribution | State an implementation and selected regression extension. No novelty priority or new compensation algorithm. |
| Assumptions | Trusted initial/action records and presented-log completeness; sealed logs can become stale. Keep the dishonest-history counterexample. |
| Controls | Four supported completion cases, incomplete history, post-seal change, and deliberate X/Y actuator faults. No always-refuse shortcut. |
| Evidence | Every assignment retained. Setup, both final saved reads, exact prepare/finish inputs, decision, action literal and cleanup have source links. |
| Unknown cases | Never replace them or fill from predictions. A wrong observed final value is scored, not excluded. |
| Reproduction | Frozen inputs, actual code, public selected data, commands, logs and separate clean replay. Private source evidence is not fully public. |
| Uncertainty | Exact counts with planned, valid and unknown denominators. Selected paired cases are not independent random draws. No population rate, p-value or confidence interval. |
| Verification | Separate evaluator and controls, native-source review, extraction review, content check, privacy scan and remote file verification. |
| Data and rights | Authorized temporary account data only. Public synthetic fields and aliases. No new license, copied source code or unrelated account content. |
| Ethics | No invitations, messages, permissions, purchases, training or permanent deletion. Keep wrong saved fields until outcome evidence, then recoverable cleanup. |
| Limits | No atomic browser action, native field history, unrestricted model skill or guarantee against arbitrary later changes. Wrong-field detection is not repair. |
| Review status | Codex generated the study, code and report. Agent checks are not human review or peer review. |
