# Source check for the browser extension

Date: 2026-10-15. The original source record remains in source_search.md.

Before the browser plan was saved, Codex made these two web searches:

1. `browser agent delayed persistence retry controlled applications terminal status RStackBench benchmark`
2. `computer use agent benchmark evaluation real browser action delay retry idempotency`

The lead reopened the repository protocol, index, main commit, and tree. It read the previous paper and unfinished task state. This is an extension of that paper, not a new daily report.

Primary sources checked:

- [CUA-Speedrun, arXiv 2609.40284v1](https://arxiv.org/html/2609.40284v1), September 30, 2026 preprint. Reopened Section 3.2, Figure 5 discussion, Section 3.3, and the returned input/output and task-interface passages. Fast observations can precede an interface update. Model and tool timing must be treated separately. Our local pilot does not reproduce the source benchmark or its speed measurements.
- [RStackBench author report](https://exzilcalanza.info/rstackbench-browser-agent-reliability/), August 14, 2026 independent preprint report. Reopened the design and model-pilot discussion, limits, reproduction notes, and AI-use statement. It distinguishes controlled localhost evidence from general browser reliability. It also includes a small model planning pilot. Thus, a real-agent pilot is not by itself a new research idea.
- [NeurIPS Paper Checklist](https://neurips.cc/public/guides/PaperChecklist), accessed October 15, 2026. Reopened as the review aid. Claims, real experimental detail, raw evidence, compute, assumptions, limits, and honest provenance remain required. No approval or submission-compliance claim is made.

Search results also showed the WebdriverIO browser-agent benchmark and the LexBench repository. Their result tables and software were not used. No claim relies on their detailed methods. Commercial summaries and secondary posts were not used as evidence.

The exact added contribution is a small executed check of the existing paper's retry rules through a real browser and agent. The application, delays, and task are controlled. The server independently records later durable effects. The experiment measures instructed policies, not an agent's natural tendency to make errors. This limited search does not prove first priority.

No source code, task, dataset, figure, or paper was copied into the browser application. Source rights and attribution remain as stated in source_search.md. No new research license is assigned.

A final citation check reopened the full author report (lines 27-127). Its exact page title is *Measuring the Gap Between Visible UI Success and Persisted State in Browser Agents*. Reference 7 uses that title. The plan and scored configuration were not changed.
