# Source search for the additional websites

Search and access date: 2026-10-15. This is a limited primary-source search. It does not prove novelty. The proposed contribution is a documented replication of the view-scope mechanism on two additional hosted table examples. It is not a new retry method, general model improvement, or estimate of natural errors.

## Sources and read limits

- ToolsQA, [Web Tables](https://demoqa.com/webtables), undated public example. Search text exposed its fields and table. Direct web extraction returned no usable text. The lead then read and operated the live page in the excluded feasibility cases. The six-field form, persistent search, duplicate rows, and reload cleanup were checked in the browser. The exact application build is not exposed.
- SpryMedia, [Add rows](https://datatables.net/examples/core/api/add_row.html), undated official example. The older `/examples/api/add_row.html` link redirected to this URL. The design agent read the description and published example code. The lead read the description and live table. Each Add requests one new row. This source is documentation, not evidence of a scored browser state. The displayed library link identifies version 3.1.4.
- SpryMedia, [row.add()](https://datatables.net/ref/core/api/row.add%28%29), undated API reference. The older `/reference/api/row.add()` link redirected here. The design agent read Description, parameters, and examples. Search and ordering apply to new rows. Scored actions use only the browser button, not this API.
- Kara, Faisal, and Nath, [WAREX](https://arxiv.org/html/2510.03285v1), arXiv v1, September 28, 2025. Preprint. The lead re-read the abstract and introduction. WAREX adds faults to browser benchmarks; this extension uses ordinary search controls on selected public demos. No numerical WAREX result is reproduced here. The prior source file records the earlier paper reading.
- Fielding, Nottingham, and Reschke, [RFC 9110, section 9.2.2](https://www.rfc-editor.org/rfc/rfc9110.html#section-9.2.2), June 2022. The lead re-read the definition of idempotence and restrictions on retrying non-idempotent requests. These are established principles. Our browser comparison does not establish HTTP request semantics for the demo sites.
- NeurIPS, [Paper Checklist Guidelines](https://neurips.cc/public/guides/PaperChecklist), undated. Initial direct open failed. A later primary search result supplied the checklist text. Relevant claims, limits, assumptions, reproducibility, data/code, settings, uncertainty, and compute items were read. It is a review aid, not conference approval.

Search also returned WuyingBrowserAgent (arXiv:2608.17319) and Designing Agent-Ready Websites (arXiv:2607.12056). Only search-result abstracts were read. They are not cited as fully checked papers and supply no result claimed here.

## Candidates not used

GlobalSQA's public practice-site introduction describes dummy automation pages. The design agent read that introduction and the no-infinite-loop limit. WebTable and SearchFilter extracts showed search, but did not establish a row-create workflow. The BankingProject page had no usable extracted content. No trial was run there. Expand Testing Notes search results indicated that an account is needed. No account was created, and no private record or message was used.

## Relation to prior work and rights

The earlier source files retain the closest retry and browser studies. The new cases extend the same paper and keep all earlier results separate. Both new sites were selected after successful feasibility checks. They are not a random website sample or additional production account services. The fixed rules use row evidence and deliberately ignore other available signals. The paper must state this restriction.

Only original prose and necessary UI evidence are published. Public task-region observations and screenshots retain provider attribution. Page source examples and unrelated navigation are excluded from public text logs. No third-party application code is redistributed. Sources retain their rights; no new license is assigned.
