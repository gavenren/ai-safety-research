# Publication checks

Review aid: https://neurips.cc/public/guides/PaperChecklist (accessed 2026-10-22). This is not NeurIPS approval or a claim of submission compliance.

| Check | Evidence and limit |
| --- | --- |
| Claims and abstract | Exact finite counts; no production or model-performance claim |
| Prior work | Source search lists queries, read scope, primary URLs, and limited novelty claim |
| Theory assumptions | Contract, metadata, and atomicity assumptions stated where applicable |
| Reproducibility | Frozen inputs, source hash, all raw cases, code, README, two runs, comparison hashes |
| Experimental details | Every configured case included; named controls; no learned policy or data split |
| Uncertainty | Complete finite enumeration; no population inference or confidence interval |
| Compute | Exact Python/platform/time receipts; standard library; no trial model calls or paid compute |
| Limits and negative results | Failure counts, unknowns/refusals, assumptions, and resource-check limit disclosed |
| Ethics and rights | New synthetic values; no external account action; citations and paraphrases; no new license |
| AI disclosure | Codex roles and absence of human/peer review stated |
| Separate review | Required before publication; see separate_review.md and audit evidence |
| Integrity | Final batch check must verify hashes, references, no secrets/private content, and remote files |

Human subjects, model training, crowdsourcing, and external datasets are not part of this study. Those checklist items do not apply. Separate agent review is not human review. Automated secret-pattern and local-link checks are aids; the publisher must also read the final diff and verify remote content.
