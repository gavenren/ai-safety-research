# Signed corrections and nonnegative balances

Date: 2026-10-29. Read [the report](report.md).

Six rules each receive 11,664 synthetic histories. Clipping the shared partial sum at zero overcounts 3,170 histories. Clipping each item separately overcounts 4,014. Signed addition and revision-based replacement are exact after the stated complete closure. These are corrected charges, not proof of a physical resource limit.

The later [production extension](live/README.md) adds 36 matched decisions on temporary Drive and Calendar records. It includes 18 verified output renames and 18 checked no-save decisions. Credits and report delivery are controlled test inputs, not provider billing.

## Repeat the simulation

Use Python 3.13.7 on a Unix-like system for the closest reproduction. Python's `resource` module is required; native Windows is unsupported. No package install, account, network, model call, or random seed is needed. Run from this folder. Output folders must not already exist.

```sh
python3 run_study.py --out rerun_a > rerun_a.log
python3 run_study.py --out rerun_b > rerun_b.log
python3 check_reproduction.py rerun_a rerun_b > rerun_bytes.json
python3 compare_independent.py --results rerun_a --out rerun_independent_a.json
python3 compare_independent.py --results rerun_b --out rerun_independent_b.json
python3 check_reproduction.py results rerun_a > saved_bytes.json
```

Every command must exit with code zero. Comparison records must have `passed: true`. The original output folders were `results` and `reproduced`. Both full runs completed. The second scientific file set is omitted from publication because all seven files are byte-identical. Its environment record and command logs remain. The byte check excludes environment records because their times differ. A changed Python or compression library can change bytes; retain and inspect any mismatch instead of claiming byte identity.

The primary corpus has 69,984 rule cases, 408,240 saved state records, 338,256 delivery steps, and 419,904 independent decision branches. Six named controls repeat primary cases; two boundary controls test refusal without complete closure. Groups overlap. Neither states nor paired branches are independent population samples.

## Files

- `plan.md`, `plan_freeze.json`: declared question, rules, input set, controls, measures, and pre-experiment hash.
- `run_study.py`, `implementation_freeze.json`: frozen main implementation.
- `independent_spec.py`, `independent_freeze.json`: separate prefix formulas frozen before main-source access.
- `compare_independent.py`, `independent_adapter_freeze.json`: schema comparison frozen before main-result access.
- `results/inputs.json`: every generated setting and order.
- `results/traces.jsonl.gz`: complete states, duplicate flags, closure flags, scores, and decisions for all primary cases.
- `results/summary.csv`, `results/paired.json`, `results/witnesses.json`: overlapping summaries, matched comparisons, and first adverse examples.
- `results/controls.json`, `results/checks.json`: complete controls and main checks.
- `results/environment.json`, `reproduction_environment.json`: actual versions, timings, bounds, and output size.
- `run.log`, `reproduction_run.log`: original successful command output.
- `check_reproduction.py`, `reproduction.json`: exact byte comparison for seven scientific files.
- `independent_comparison.json`, `independent_reproduction_comparison.json`, `independent_run.log`, `independent_reproduction_run.log`, `independent_review.md`: separate checks and their scope.
- `source_search.md`, `references.bib`, `source_review.md`, `design_review.md`, `final_review.md`, `changes.md`: sources, reviews, and change record.
- `package_checks.json`, `manifest.json`: publication checks and file sizes/hashes. The manifest excludes itself.

Read compressed traces with Python `gzip.open` and `json.loads`. Each line is one complete rule case. The inputs file maps its numeric case ID to the four values and delivery order. Repeated IDs retain identical fields. Source encodings are specified in the plan and generated by `reports`.

## Limits and review status

All admissions occur after complete receipt and a trusted finality declaration. The greatest observed revision alone does not prove closure. The source values, identities, revisions, and signed deltas are assumed correct. The original simulation does not test a production service. The later extension tests saved website fields and local accounting decisions. Neither test measures a financial transaction or a physical compute refund.
