# Publication review aid

Date: 2026-10-22. The [NeurIPS Paper Checklist](https://neurips.cc/public/guides/PaperChecklist) is used as a review aid. This file does not claim NeurIPS approval, peer review, certification, or submission compliance.

| Item | Evidence and scope |
| --- | --- |
| Claims | The report limits its counts to the complete finite corpus. The oracle scores predicate outputs, not all input observations. Source restoration and reader service are separate measures. |
| Limitations | Two bits, two readers, one writer, one interrupted boundary, complete gate mediation, and local SQLite are explicit. No website or language-model performance claim is made. |
| Theory | The report and independent review give the three serial cuts and exact count derivation. These are finite calculations, not a new general isolation theorem. |
| Method | The plan, case order, hypotheses, measures, controls, and stop gates were saved before implementation and execution. Hash receipts preserve this record. |
| Reproduction | Code, schema, configuration, logical rows, worker logs, physical databases, commands, and environment versions are supplied. The independent check reopens every database. The clean-repeat record states its scope and result. |
| Statistical uncertainty | This is exact enumeration of a designed set. No confidence interval, significance test, or population failure probability is claimed. Behavioral multiplicity and generalization limits are stated. |
| Compute | Actual CPU use, two duration clocks, hardware architecture, versions, process count, and limits are saved. No paid compute or model API charge was incurred for the experiment. Peak memory and energy use were not measured. |
| Ethics and effects | Only synthetic local data was used. Saved action records model conditional decisions; they do not send real external actions. No human subject, private account, or production website was tested. |
| Safeguards | The release contains a bounded local database test. It has no real-service exploit or actionable instructions for serious harm. Zero counts and refusals must not be treated as general safety certificates. |
| Rights | Primary sources are cited and paraphrased. No paper, figure, code, or dataset from a source is republished. SQLite is public-domain software. No new license is assigned to the user's work. |
| New assets | README documents all files, record fields, expected outcomes, commands, and limits. The saved records are synthetic. |
| Human subjects and approval | Not applicable. No participants or human account records were used. No institution or ethics board endorsement is claimed. |
| AI use | The report states that Codex generated the study and report and names the AI roles. No human authorship or peer review is implied. No model runs inside a scored trial. |
| Source checks | source_review.md and source_supplement.md give URLs, dates, queries, reading scope, access failures, and excluded leads. Preprints are identified. No numerical result is imported from a source. |
| Text and private data | Manual source comparison found no copied source passage in the report. Automated checks scan common secret and private-path forms. These are bounded checks, not a comprehensive plagiarism or privacy certification. |
| Publication | Remote verification is a separate final step. A local file, local check, browser upload selection, or attempted commit is not proof of publication. |

The separate logical and content reviews state findings and their resolution. The change log retains implementation and publication-check issues. No failure is replaced with a favorable trial.
